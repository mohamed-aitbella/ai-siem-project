# 🛡️ AI-Powered SIEM Project

## 📖 Overview
A smart SIEM (Security Information and Event Management) system powered by Machine Learning to analyze network traffic and detect anomalies.

## 🚀 Features
* **AI Threat Detection:** Uses ML models to differentiate between normal traffic and cyber attacks.
* **Data Processing:** Cleans and prepares network data (e.g., NSL-KDD dataset).
* **Infrastructure Automation:** Ready for Docker deployment.
